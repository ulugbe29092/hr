# NEXUS ERP CRM HR AI PLATFORM

## Loyiha Haqida
Enterprise darajadagi ERP + CRM + HRM + AI Platform — katta bizneslar, korporatsiyalar va IT kompaniyalar uchun.

## Modullar
- **ERP** — Korxona boshqaruvi (Finance, Inventory, Procurement)
- **CRM** — Mijozlar boshqaruvi (Pipeline, Kanban, Communication)
- **HRM** — Hodimlar boshqaruvi (Attendance, Payroll, Leave)
- **AI System** — AI Assistant, Analytics, Automation
- **Recruitment** — Hiring platform with AI resume analysis
- **Analytics** — Realtime BI Dashboard
- **Finance** — Accounting, Tax, Reporting

## Tech Stack
- Frontend: Next.js 15, TypeScript, Tailwind CSS, Shadcn/ui, Framer Motion
- Backend: NestJS, Node.js, PostgreSQL, Redis, Elasticsearch
- DevOps: Docker, Kubernetes, Nginx, GitHub Actions, AWS

## Arxitektura
Enterprise Modular Architecture — Microservice ready, API-first, Cloud-native

## Standartlar
- OWASP Security
- RBAC + RLS
- Multi-tenant
- Realtime (Socket.io)
- AI-powered
